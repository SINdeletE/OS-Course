# Загружаемый модуль ядра Linux, преобразующий ввод стилуса графического планшета в действия мыши

Разработать загружаемый модуль для ОС Linux, позволяющий использовать стилус графического планшета в качестве мыши через Type-C соединение.
Движение стилуса по графическому планшету должны преобразовываться в относительные перемещения курсора мыши, касания стилусом планшета -
в нажатие левой кнопки мыши, а нажатия на кнопку стилуса - в нажатия правой кнопки мыши.

Планшет: XP-PEN Deco Fun L
ОС: Ubuntu 24.04.3 ARM64
Версия ядра: 7.0.0-43-generic

Язык: C
Файл: src/main.c
Команды компиляции, загрузки модуля, выгрузки модуля: Makefile
