# USB-драйвер XP-PEN Deco Fun L

## Размещение и результат

**Весь проект размещается в целевой Ubuntu. Сборка, тестирование, загрузка и выгрузка модуля выполняются локально внутри этой ОС**, из каталога проекта. Makefile и документация рассчитаны на такой способ работы.

Целевая система: Ubuntu 24.04.3 ARM64, ядро `7.0.0-43-generic`, GCC 13.3. Реализовать модуль `xppen_mouse` через `struct usb_driver`, самостоятельно принимающий USB-пакеты через URB. Собственная логика использует возможности C99; Kbuild собирает модуль в штатном режиме GNU11.

## Реализация модуля

- Разместить код в `src/main.c`. Поддерживать только устройство `28bd:0932`, интерфейсы 0 и 1.
- Интерфейс 0 занять без опроса и создания устройства ввода, чтобы подавить исходные события мыши и клавиатуры планшета. Интерфейс 2 оставить штатному драйверу.
- На интерфейсе 1 создать устройство мыши и запустить interrupt IN URB. Endpoint выбирать по дескриптору; подтверждённые параметры — `0x82`, максимальный пакет 64 байта, интервал 4 мс.
- Перед приёмом установить Report Protocol запросом `SET_PROTOCOL(1)`. При ошибке прекратить подключение и освободить ресурсы.
- Использовать DMA-совместимый буфер размером по endpoint. В completion callback проверять статус и фактическую длину, обрабатывать данные и повторно отправлять URB с `GFP_ATOMIC`.
- Принимать отчёт №7 длиной 10 байт. Байт 1: `0x01` — касание, `0x02` — первая боковая кнопка, `0x20` — перо в зоне считывания. X находится в байтах 2–3, Y — 4–5; формат little-endian, диапазон `0…32767`.
- Формировать `REL_X`, `REL_Y`, `BTN_LEFT`, `BTN_RIGHT` и синхронизацию пакета. Давление, наклон и вторую боковую кнопку игнорировать.
- Двигать курсор при наведении и касании, используя разность соседних координат. Первый отсчёт после подключения или возвращения пера задаёт начало отсчёта без движения.
- Добавить параметр загрузки `divisor=8`, диапазон `1…1024`, без изменения во время работы. Сохранять знаковые остатки деления отдельно по осям.
- Касание удерживает ЛКМ, первая боковая кнопка — ПКМ. При выходе пера из зоны считывания освобождать кнопки и сбрасывать координаты и остатки; выход обрабатывать независимо от значений координат.
- Хранить состояние отдельно для каждого устройства. Неподходящие и повреждённые отчёты игнорировать без изменения состояния.
- При отключении, выгрузке и suspend останавливать URB и recovery work, дожидаться завершения callbacks, освобождать кнопки и ресурсы. После resume/reset восстановить режим отчётов и начать движение с нового отсчёта.
- Отменённые URB не отправлять повторно. При `-EPIPE` восстанавливать endpoint через workqueue; при неудаче прекращать приём, освобождать кнопки и писать причину в журнал.

## Makefile и документация

- Предусмотреть `make`, `make load`, `make bind`, `make unload`, `make clean`. Результат — `xppen_mouse.ko`.
- Использовать локальные заголовки работающего ядра: `/lib/modules/$(uname -r)/build`; разрешить переопределение `KDIR`.
- `make load` загружает модуль и привязывает подключённый планшет. `make bind` повторно выполняет привязку после переподключения USB.
- Перепривязывать только интерфейсы 0 и 1 устройства `28bd:0932` на шине USB, сохраняя предыдущие привязки. При частичной ошибке восстанавливать их.
- `make unload` выгружает модуль и восстанавливает штатные привязки присутствующих устройств. Глобально `usbhid` не выгружать.
- После переподключения планшета использовать `make bind`; правила udev не устанавливать.
- В `README.md` описать подготовку Ubuntu, зависимости, выполнение команд из каталога проекта, необходимые права, чувствительность и проверку через `evtest`. Проброс планшета в Parallels указать как предварительное условие.

## Проверка и приёмка

- Все проверки выполнять из копии проекта внутри Ubuntu.
- Собрать модуль с `W=1`; проверить ARM64 и соответствие `vermagic` работающему ядру.
- Декодирование и расчёт событий оформить как функции без вызовов ядра.
- На планшете проверить наведение, касание, перетаскивание ЛКМ, ПКМ первой кнопкой, отсутствие дублирования и скачков.
- Проверить отключение, повторное подключение с `make bind`, повторную загрузку и выгрузку, suspend/resume. После выгрузки штатная работа планшета должна восстановиться; виртуальные мышь и клавиатура Parallels должны продолжать работать.
- Работу USB-транспорта и URB подтверждать на реальном планшете; результаты аппаратной проверки фиксировать отдельно от сборки.
